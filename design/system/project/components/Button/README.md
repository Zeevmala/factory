An action. Four kinds: primary, default, quiet and danger.

**You provide:** a `button` (or a link styled as one) with a label that says what happens: "Navigate", "Share link", "Leave session".

- `cw-button--primary`: the one main action in a view. Never two.
- Default: secondary actions.
- `cw-button--quiet`: low-emphasis actions beside a primary button.
- `cw-button--danger`: destructive actions only, and say what is destroyed.
- Disabled buttons keep their label; say why nearby if it is not obvious.
- Height is 36px with a pointer and 44px on touch. Do not set a height.
