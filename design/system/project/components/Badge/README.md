A short status or count beside the thing it describes.

**You provide:** two or three words, and optionally `span.cw-badge__dot` before them.

- Neutral for counts and labels. `--accent` for live or selected. `--success`, `--warning`, `--danger` for state.
- The word carries the meaning; the colour repeats it. A badge that only changes colour fails colour-blind readers.
- Use the condensed label style as given. Do not set badges in capitals.
