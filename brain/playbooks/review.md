# Review playbook

Rules for reviewer runs, learned from earlier reviews: what reviewers missed that a human later caught, and what they blocked that a human overrode. The weekly curate run rewrites this file; you approve the diff. Each rule names the evidence it came from.

Keep it under 30 rules. When a rule is added, the weakest one goes.

## The bar

Would the best team in the world ship this change as it is? If not, it blocks, with the concrete reason. A reviewer that cannot name the reason does not block.
